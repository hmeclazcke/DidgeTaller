## Production decisions

- **Saved diagnostics, comparison, association and optimization:** one revocable
  typed request protocol owns progress/previews, completion and cancellation.
  Session selection is a pure admission rule; disposal is permanent. The original
  native tests fail four disposed commands, then expose optimizer executor reuse.
  Controlled callbacks cover replacement, queued events, duplicate terminal
  outcomes, synchronous completion, reentrancy and observer cleanup.
- **Canonical trace:** independent per-session grants preserve parallel library
  previews. Captured input facts travel with each immutable request; decoded
  products are bounded and selected/current entries retained. Removal, key reuse,
  retry, failure, pinning and disposal cannot publish another session's result.
- **Playback:** permanent disposal revokes commands before backend release. A
  genuine native regression publishes a playback error after ViewModel clear;
  the corrected controller cannot construct another MediaPlayer, accept an old
  callback, reinstall a loop or schedule a poll. Stop remains reusable; close does
  not. Preparation/pause intent and confirmed latest seeking remain unchanged.
- **Offline WAV analysis:** WavAnalysis now orchestrates validated source bounds,
  one reusable window pass, sample-weighted spectral accumulation, independent
  flute cadence and accepted-point statistics. It no longer owns every loop and
  summary decision. The baseline window overflow and negative absolute timestamp
  are independently reproduced against the original source. Safe subtraction
  and division-first conversion correct those errors without changing valid
  historical numerical outputs, WAV bytes, detector thresholds or index formats.
- **Session presentation:** a pure SessionInspector selects actual evidence and
  resolves localized text through a narrow resource port. Canonical components,
  raw periodicity and SWIPE remain separate; missing intervals remain missing.
  Empty wave/tile inspection previously throws; explicit empty/shape checks now
  return the existing localized unavailable state. Loading is distinguished from
  analyzed missing evidence. AnalysisInterval owns locale-aware numeric parsing
  and validated recording units, replacing nullable UI decisions and unsafe !!.

## Measurement reviews and enforcement

Ordinary changed named pure functions receive source/JVM-correspondent complexity
and method-line coverage. Constructors, initializers, immutable carriers, derived
accessors and scoped wiring closures have no independent Detekt named-function
MCC; their narrow content-bound reviews link their behavioral owner tests.
Compose transformation reviews retain source declaration identity and actual
native evidence without inventing a JVM method score. Three changed Android
command bridges retain their existing source responsibilities and risk ceilings:
emptyTrash MCC4, destination change6, session deletion7. Their line coverage is
reported separately for JVM and Android. They are not new pure algorithms exempted
from testing. No numerical baseline, threshold, mutation operator or failure
semantics is relaxed. Any semantic edit expires its reviewed fingerprint.
